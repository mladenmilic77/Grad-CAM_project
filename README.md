# Grad-CAM – Visual Explanations from Deep Networks

Project focused on Explainable Artificial Intelligence (XAI), with an emphasis on Grad-CAM (Gradient-weighted Class Activation Mapping).

## Contents

- `01_Captum_Tutorial.ipynb` – introduction to model interpretability using Captum
- `02_GradCAM_ResNet18.ipynb` – Grad-CAM implementation and experiments using ResNet18
- `img/` – images used for classification and segmentation experiments
- Project report
- Presentation

- Explainable Artificial Intelligence (XAI)
- Post-hoc interpretability
- Attribution-based explanations
- Grad-CAM
- Convolutional Neural Networks
- ResNet18
